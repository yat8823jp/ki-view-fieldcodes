# kintone フィールドコード表示

kintone で現在表示しているフィールドのフィールドコードを画面に表示・非表示切り替える Chrome 拡張機能です。表示されたチップをコピーすればクリップボードにコピーできます。

## バージョン

### v2.0.0（2026年4月）

- **メジャーバージョン 2.0.0** としてリリース
- **アプリ設定のフォーム（フィールド設定）画面に対応**: フィールドの追加・並び替えなどを行うフォーム設定画面でも、各フィールドにフィールドコードをバッジ表示

### v1.4.1（2026年4月）— マイナーアップデート

- **グループのフィールド表示対応**: グループフィールドおよびサブテーブル本体のフィールドコードを、レコード詳細・編集画面とフィールドコード一覧に表示

### v1.4.0（2026年4月）

- **フィールド一覧にコピーボタン追加**: フィールドコード一覧パネルにコピーボタンを追加

### v1.3.0（2025年3月）

- **フィールドコード一覧表示機能追加**: レコード画面でフィールドコード一覧パネルを表示。×ボタンで閉じ、閉じた後は「フィールドコード」ボタンで再表示可能
- **テーブル内のフィールド表示対応**: サブテーブル内のフィールドにもフィールドコードを表示

### v1.2.0（2025年3月）

- **レコード編集画面に対応**: レコード編集・追加画面でもフィールドコードを表示できるようになりました（従来は詳細・一覧・印刷画面のみ対応）

### v1.0.0

- 初回リリース（レコード詳細・一覧・印刷画面対応）

## 機能

- **レコード詳細画面**: 各フィールドにフィールドコードをバッジ表示
- **レコード編集・追加画面**: 同上
- **レコード印刷画面**: 同上
- **レコード一覧画面**: 表形式の一覧で各列にフィールドコードを表示
- **アプリ設定のフォーム（フィールド設定）画面**: フォーム上の各フィールドにフィールドコードをバッジ表示（アクセス権・通知などその他の管理画面は対象外）

## インストール方法

1. Chrome で `chrome://extensions/` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`vew-fieldcodes`）を選択

## 使い方

1. kintone のアプリ画面（レコード詳細・一覧・編集など）またはアプリ設定のフォーム（フィールド設定）画面を開く
2. ブラウザのツールバーにある拡張機能アイコンをクリック
3. 「表示する」のトグルをオンにするとフィールドコードが表示されます
4. オフにすると非表示になります

設定は保存されるため、次回 kintone を開いたときも同じ状態で表示されます。

## バッジ色とコピー可否

- **オレンジのバッジ**: クリックでフィールドコードをコピーできます（レコード詳細・編集・一覧など）
- **グレーのバッジ**: コピーできません（主にアプリ設定のフォーム編集画面。ドラッグ操作との競合を避けるため）
- フィールドコード一覧パネルのバッジは、通常どおりコピー可能です

## 対応環境

- Chrome（Manifest V3 対応）
- kintone（cybozu.com / cybozu.biz / kintone.com）

## 注意事項

- アプリ設定のうち、**フォーム**タブ（例: `/k/admin/app/flow?app=…#section=form` や `/k/admin/app/form`）以外の管理画面（一覧・グラフタブ、アクセス権、通知など）では表示しません
- テーブル内のフィールド、関連レコード、ステータス、作業者など、一部のフィールドは kintone API の制限により取得できない場合があります
- kintone のアップデートにより、表示が変わる可能性があります
